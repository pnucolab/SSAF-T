# Tutorials

The repository's `notebooks/` holds one worked example per data kind. Each starts with the commands
that download its public dataset into `notebooks/data/` and writes results to `notebooks/outputs/`.

| notebook | platform | map |
|---|---|---|
| [`tutorial_xenium_kidney_3d.ipynb`](https://github.com/pnucolab/SSAF-T/blob/main/notebooks/tutorial_xenium_kidney_3d.ipynb) | Xenium, mouse kidney (GEO GSE269719) | 3D |
| [`tutorial_visiumhd_small_intestine.ipynb`](https://github.com/pnucolab/SSAF-T/blob/main/notebooks/tutorial_visiumhd_small_intestine.ipynb) | Visium HD, mouse small intestine (10x Genomics) | 2D |

For scRNA-seq, where CeLLMan is used on its own, see
[`CeLLMan/notebooks/TS_lung.ipynb`](https://github.com/pnucolab/CeLLMan/blob/main/notebooks/TS_lung.ipynb).
